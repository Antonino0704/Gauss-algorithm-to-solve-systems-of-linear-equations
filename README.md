# Gauss algorithm to solve systems of linear equations
A program that solves systems of linear equations with Gauss algorithm

The program works when the problem is well-posed

# Installation
You can build the lib or download [here](https://github.com/Antonino0704/Gauss-algorithm-to-solve-systems-of-linear-equations/releases)

To include it in other projects, you need to use the [gauss.h](https://github.com/Antonino0704/Gauss-algorithm-to-solve-systems-of-linear-equations/blob/main/source/gauss.h) header file and the libgauss.a library

# Build
Clone repo and run
`make`
